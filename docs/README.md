# RiverSentinel — Docs

Plain-language reconstruction of this project from the problem statement forward, written to
reconcile what `README.md` claims with what `RESEARCH_LOG.md` and the actual code show was built.
Start here, read in order:

1. [01-problem-statement.md](01-problem-statement.md) — the problem, and which numbers behind it
   are independently verified vs. asserted without a source.
2. [02-approach-and-methods.md](02-approach-and-methods.md) — the two-track approach; where the
   plan (YOLOv8-Seg) and the build (Google Open Buildings) diverged, and why.
3. [03-pipeline-walkthrough.md](03-pipeline-walkthrough.md) — what each of the 8 notebooks and
   each app page actually does and outputs.
4. [04-status-and-gaps.md](04-status-and-gaps.md) — the honest checklist: built & verified, built
   with caveats, and claimed in the README but not built at all.

`RESEARCH_LOG.md` at the repo root remains the authoritative, chronological record of the build —
these docs are a distilled reference on top of it, not a replacement.
